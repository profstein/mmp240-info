Site Content

Based off of your planning documents, start adding content to your pages.

Remember to use semantic elements. These are the main sectioning elements for pages

  • header | main | footer on each page.
  • section: for page sections with headings
  • article: a self-contained composition (this means it would make sense if only read that and none of the rest of the page).
  • nav: used in your site navigation in the header.
  • div: used if no other element makes sense, or if you're just grouping things for visual purposes or to add interactivity.
