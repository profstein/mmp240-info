New and Useful Topics

Here are some new topics that have been added, some we've seen that are useful and some are ported over from Brightspace. A number have been added to the new CSS category. I will add some as the week goes on.

  • Project 4 Review prompts These prompts are designed to help you make sure you're on the right track at the beginning of the project, while you're making it, and a check when you're about done.
  • Fluid Font Scaling with Clamp() If you're already using rem units and CSS variables, this technique allows you to have fluid type scaling in relation to browser size in one line of CSS.
  • Using Web Fonts from a Font Service How to use Google Fonts and Adobe Fonts
    • Many of you do not realize that through your Adobe license from CUNY you have access to use Adobe web fonts in your projects. This page explains how to use them. I will try to also make a video of that this week. This is similar to using Google Fonts.
    • Some fonts they have at Adobe Fonts: Futura, Proxima Nova, Avenir Next, FF Din, Myriad, Freight Text, Mrs Eaves, New Astro, Elizeth
    • Adobe also has this Collections Page which groups fonts around themes.
  • Interactive Topics These include using JavaScript and will fulfil the interactive requirement of Project 4.
    • Creating a Lightbox Gallery This shows how to make a gallery of images that shows as a modal lightbox.
    • Creating an Accordion This shows how to make an accordion.
  • CSS Variables Ported from Brightspace, info on how to use CSS variables.
  • Cards Examples and videos on using cards (moved over from Brightspace with some additional examples.
  • Flexbox What is and how to use Flexbox in layout (also moved over from Brightspace with updates).
  • Navigation How-tos and examples of implementing responsive navigation
