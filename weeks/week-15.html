Week 15: 12/1/25-12/7/25
Site Visualizations & Starting Your Build

Outline for the Week

  • Introduction
  • Part 1: Site Visualizations
  • Part 2: Set Up Your Base Responsive Site
  • Assignment for the Week
  • [optional] Add content to pages

Intro

This week you’ll begin building your sites. Before you jump into code, you’ll create a set of visualizations that help you plan your structure and design, and that help me confirm you’re on the right track.

Goals for This Week

  • Create and refine site visualizations:
    • Sitemap
    • Wireframes
    • Color & type styles
  • Set up your project using the base responsive repository.
  • Build stub pages for all the pages in your sitemap.
  • Get your navigation working between those pages.
  • (If time) Start adding content to at least your home page.

Part 1: Site Visualizations

Before writing code, you’ll create three visuals that professionals commonly use when planning websites. These will live in the Figma template I’ve shared with you.

Project 4 Site Planning Figma File

The file below has space and templates for you to create a Sitemap, Wireframes and Type and Colors styles for your project. Download it, open it in Figma and then follow along.

Download Project 4 Site Planning.fig

1. Sitemap

  1. Create your sitemap in FigJam.
    • Use simple boxes and arrows to show the pages of your site and how they connect.
    • Focus on clarity: what are your main pages and what lives under each one?
  2. When your sitemap is ready, copy it from FigJam into the Sitemap page of the Figma template for your site visualizations.

Resource: Watch the short sitemap video for a walkthrough.
▶ View Sitemap Video (FigJam to Figma) on YouTube

2. Wireframes

On the Wireframes page of the Figma template, sketch out the basic layout of your key pages. You’ve done wireframing before, so reuse that knowledge here.

  • Focus on structure: headers, navigation, main content areas, footers.
  • Don’t worry about detailed colors or typography yet—keep it low-fi.
  • Use what you learned from previous wireframe assignments to save time.

Resource: Quick wireframe video reminder.
▶ View Wireframes Refresher Video on YouTube

3. Type & Color Styles

On the Type & Color Styles page in Figma, define the visual language of your site:

  • Set up text styles for headings, body text, captions, etc.
  • Set up color styles for backgrounds, text, accents, and interactive elements.
  • You can build from previous assignments where you already explored color and typography.

Note: It’s completely fine if you adjust your sitemap, wireframes, or styles later as you start building. Design is iterative.

Resources

Resource: Quick Type and Color video reminder.

Links

  • Palettemaker App: helps to choose colors
  • Adobe Color: has a number of tools including palette generators based on color theory and accessibilty toools.
  • Colour Contrast Checker: Checks if text and background color contrast meets accessibility guidelines.

Part 2: Set Up Your Base Responsive Site

Once you’ve started your visualizations in Figma, it’s time to set up the code structure for your site using the base responsive repository I’ve provided.

1. Get the Base Repository

  • Open the link to the base responsive repository.
  • Follow the instructions to use it as the starting point for your project (clone, fork, or download as appropriate for our workflow).
  • Open the project in VS Code.

This base project includes:

  • Starter HTML structure.
  • Responsive CSS, including variables you can reuse.
  • A layout that will help you focus on content and design instead of boilerplate setup.

Resources

Resource: Video on how to use the base responsive template.
▶ View Base Responsive Template Video on YouTube

  • Type Scale Generator: This can be used to choose a different scale and get new type sizes that you can copy and paste into base.css

2. Build Stub Pages for Your Site

Use the sitemap you created to decide which pages you need, then:

  1. Set up your home page first using the base layout:
    • Include a clear <header>, <main>, and <footer>.
    • Inside <main>, add a simple <h1> with the page title (for now you can leave it mostly empty).
  2. Create additional HTML files for each page in your sitemap.
    • Copy over the same header and footer structure so they match across your site.
    • In each page’s main area, add an <h1> title so you know which page you’re on.

Resources

Resource: Video on how to use the base template to make stub pages.
▶ View Stub Pages Video on YouTube

The above video also shows getting the basic nav working.

3. Get Your Navigation Working

Once all your stub pages exist:

  • Set up navigation links in the header that point to each page.
  • Test clicking around to be sure all links work and every page loads correctly.
  • Make sure the pages in your navigation match the pages in your sitemap.

Using AI to Support Your Work

You are encouraged to use AI tools to support (but not replace) your thinking.

Remember: AI is there to handle busywork and help you experiment. You are still responsible for deciding what belongs on your site and how it should look and behave.

Assignment for the Week

The assignment this week has two parts. Sitemap, Wireframs and Styles.

  • Part 1: Create a Figma file with:
    • Sitemap on the Website Sitemap page. (draw in FigJam and paste onto the page)
    • At least initial wireframes on the Website Wireframes page.
    • Initial type and color styles on the Type & Color Styles page.
  • Part 2: Create the GitHub repository with Stub pages:
    • Base responsive project set up and running.
    • Stub HTML pages for each page in your sitemap.
    • Working navigation links between all pages.
  • Part 3: Submit your work to the assignment Week 15: Project 4 Visualizations and Stub Pages
    • Upload the Figma file with the Site Map, Wireframes, Type and Color styles
    • Paste in a link to your GitHub Repository. Remember to commit and sync your changes.
This assignment is due on Sunday, December 8.

Part 3: Begin Adding Content to Pages (Optional This Week)

If you finish the visualizations and stub pages with working navigation, start adding real content based on your wireframes and type/color styles.

  • Begin with your home page or another key page.
  • Add headings, paragraphs, and sections that match your wireframe structure.
  • Use your defined color and type styles from Figma as a guide while you style elements in CSS.

If you don’t get to this step, that’s okay—next week will focus on filling out content and adding interactive elements.
