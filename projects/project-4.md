# Project 4: Responsive Showcase Site

In this project you get to show everything that you've learned in the class while also diving deeper into the planning documents. The overarching goals here are for you to work on a site that is interesting to you, shows what you can do in a multi-page side and hopefully have something that you can put in your portfolio.

## Requirements

- **TOPIC** Choose from one of three: 1)Travel / Local Guide, 2) Hobby Site, 3) How-To Guide
- **PLANNING** Complete the Creative Brief and Site Visualizations (note that these will be graded separately from the final itself).
- **Site Structure** At least 4 pages (you can do more). One page should be about you or the project.
- **Design Requirements** 
    - Scanability & Visual Hierarchy - Content is structured so that sections are easy to distinguish at a glance and a clear hierarchy is established.
    - Layout and Gestalt Principles - Use of spacing, grouping, alignment, and color to create a coherent layout. Pages feel intentional, balanced, and visually organized, applying Gestalt principles to structure the page.
    - Typography choices match (or thoughtfully evolve from) planning doc. Heading and body text use appropriate fonts, sizes, weights, and spacing to establish a typographic hierarchy. Text is readable at all screen sizes with reasonable line lengths. 
    - Colors follow (or thoughtfully evolve from) the planned palette. Link/button colors are consistent. Overall palette is cohesive and supports the site’s mood/vibe.
- **Media Requirements** Includes images and at least **one additional type of media** (e.g., video embed, audio). Content is appropriate for the chosen topic and target audience. All media credits the author.
- **Interactive Requirements** Your site must have at least one interactive element (not including the navigation).
    - Examples: Accordion; Lightbox image gallery; JavaScript-based UI pattern like interactive cards or filter buttons.
- **Accessibility Requirements** 
    - **Alt Text** | All non-decorative images include meaningful `alt` attributes. Media embeds include clear labels or titles where appropriate.
    - **Color Contrast & Legibility** | All text and background color combinations (including links, nav and buttons) have greater than 4.5 contrast. Main body text/background is at least 7.0 contrast. 
- **Technical Requirements** RWD stands for Responsive Web Design
    - HTML is valid, well-structured, and semantic. Proper elements are used (header, nav, main, section, article, footer, etc.)
    - CSS has proper syntax. Uses consistent naming, selectors, and spacing. No major redundancy or obviously conflicting rules. 
    - CSS Variables are used for type, color and spacing properties.
    - RWD: Multiple Layouts: Media Queries are used to change layout in a meaningfully way to adapt for mobile and desktop screens. Other techniques like R.A.M. for CSS grid can be used.
    - RWD: Fluid Layout - Uses fluid units, grid and flexbox to create responsive, flexible layouts. Grid should be the primary layout for overall sections, Flex can be used in sections or for components. Avoids fixed widths.
    - RWD: Responsive Media - Images and other media (video, audio, embeds) scale proportionally and never breaks or overflows the layout.
    - Navigation & UX - Navigation is clear, consistent across all pages, and fully responsive. Users can easily move through the site.
- **Published on Netlify via GitHub** | Site is deployed successfully using **Netlify** connected to a **GitHub repo**. All pages and assets load correctly. Links used for navigation and content are working.
