CSS Variables

Reference and how to use CSS variables.

CSS Custom Properties, commonly known as CSS Variables allow you to create consistency in your site and more easily change property values (colors, fonts, font sizes etc) quickly. 

These are very helpful to use, especially as your site gets larger and you have more styles to keep track of and keep consistent.

On a responsive site, you often want to adjust the spacing used to fit the screen size. For example smaller screens are usually held closer to people's faces and can have smaller spacing. As screens get larger spacing can increase.

To avoid rewriting a lot of spacing rules in our media queries, we can use CSS variables to define the spacing and then change one variable to change all of our spacing. This will be accomplished with a combination of 

  • CSS CSS Custom Properties aka Variables
  • Calc function: https://developer.mozilla.org/en-US/docs/Web/CSS/calc

SETTING CSS CUSTOM PROPERTIES (Variables)

Variables are set by defining a name and giving it a value.

  • The name always starts with --
    • There can't be any spaces in it
  • Then there is a :
  • Then the value. 
    • You can use a lot of things here from numbers to text to other CSS variables

Generic format

--name : value;

SETTING SPACE PROPERTIES

Let's try this and start with defining a base space unit

:root{
	--space-unit: 1rem;
}

Then you can add in multiples of that using calc. Calc allows you to do math in CSS and here we will use it to multiply the space unit.

:root{
	--space-unit: 1rem;
	--space-xs: calc(var(--space-unit) * 0.25);
	--space-sm: calc(var(--space-unit) * 0.5);
	--space-md: calc(var(--space-unit) * 1);
	--space-lg: calc(var(--space-unit) * 1.5);
	--space-xl: calc(var(--space-unit) * 2);
	--space-xxl: calc(var(--space-unit) * 3);
}

so now we have CSS variables for spaces that range from a fourth of the base font (-- space-xs) to 3 times the base font (--space-xxl)

Remember that rem is based on the base font size for the html element, so we can set the rem value like this:

html{font-size:16px;}

USING CSS CUSTOM PROPERTIES (VARIABLES)

Most of the time you will use the variable in place of a value in one of your CSS properties. To use a variable you write var() wit the name of the variable in the parentheses.

Generic: var(--name, fallbackValue)

margin-bottom: var(--space-md, 1rem);

The fallback value is optional so this works too: var(--name)

margin-bottom: var(--space-md);

Let's use some of our space variables

section{ margin-top: var(--space-xl);}

p{ section{ margin-bottom: var(--space-md);}

images{
	display: grid;
	grid-template-columns: repeat(2, 1fr);
	gap: var(--space-sm);
}

Now use the spacing units throughout your page to keep spacing consistent and easily changeable.
