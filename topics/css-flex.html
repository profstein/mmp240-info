Flexbox

Intro

You’ve used CSS Grid to create multi-column layouts for galleries and pages. Another important tool for layout is Flexbox. Grid and Flexbox share some similarities, but they solve different problems.

Overview

How Flexbox is Similar to Grid

  • Both require a container element. The layout only applies to the container’s direct children.

  • Both use the display property to activate

  • Both support a gap property to control spacing between items.

  • Both give you powerful ways to align and distribute content.

.container {
  display: flex;
  gap: 1rem;
  flex-direction: row;
  align-items: space-between;
}

How Flexbox is Different from Grid

There are also some differences

  • Direction (dimensions)
    • Grid lays out items in two dimensions (rows and columns together).
    • Flexbox works in one direction at a time — either row (horizontal) or column (vertical).
      flex-direction: row;
      flex-direction: column;

  • Flow: Flexbox items can shrink, grow, and wrap, but always along a single main axis.

  • Simplicity: Because you don't have to define (and then change) columns, Flexbox is great when you don’t need the full power of a grid but want quick, flexible alignment.

When to Use Flexbox

Flexbox is best for situations where content should be aligned in one direction (row or column). For example:

  • Navigation bars — items in a row, spaced apart. (You already saw this when styling navigation.)

  • Card layouts — stack content vertically inside a card (image → text → button). Flexbox makes it easy to push the button to the bottom.

  • Form controls — align labels and inputs in rows.

  • Groups of related items — like social icons (see example below).

  • Horizontal Scroll – When you have a number of items that go offscreen to the right. Example 1
