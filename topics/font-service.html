Using Web Fonts from a Font Service

This is the simplest and fastest way to use web fonts. 

You can include them in your HTML in two ways — either with a <link> in your HTML file, or with @import in your CSS file.

Google Fonts

Link Method

Remember that you will need to add the <link> element to every page of your web site.

  1. Go to https://fonts.google.com.

  2. Choose a font and click Get Font or the + icon. Do this for all of the fonts you will use (try no more than 3).

  3. Under “Use on the web” → <link>, copy the code.

    It will look something like this:

<link href="https://fonts.googleapis.com/css2?family=Lato:wght@400;700&display=swap" rel="stylesheet">

  1. Paste that line inside the <head> of your HTML document, BEFORE your own CSS file link:

<head>
  <meta charset="UTF-8">
  <title>My Project</title>
  <link href="https://fonts.googleapis.com/css2?family=Lato:wght@400;700&display=swap" rel="stylesheet">
  <link rel="stylesheet" href="style.css">
</head>

  1. Copy the font-family declaration on the Google Fonts page and then, in your CSS file, paste it in where you need it:

body {
  font-family: "Lato", sans-serif;
}

@import Method

This is a bit simpler but can be longer to load.

  1. On Google Fonts, copy the code under “Use on the web” → @import.

    Do NOT copy the <script> tags, jus the @import. It looks like this:

@import url('https://fonts.googleapis.com/css2?family=Lato:wght@400;700&display=swap');

  1. Paste that line at the very top of your style.css file — it must come before any other CSS rules.

@import url('https://fonts.googleapis.com/css2?family=Lato:wght@400;700&display=swap');

body {
  font-family: "Lato", sans-serif;
}

  1. Copy the font-family declaration on the Google Fonts page and then, in your CSS file, paste it in where you need it:

body {
  font-family: "Lato", sans-serif;
}

Adobe Fonts

Adobe Fonts (formerly Typekit) lets you use high-quality fonts on your website.

To use them, you’ll need to create a web project on https://fonts.adobe.com and then connect it to your site with either a <link> tag or an @import rule.

Link Method Adobe

✅ Create and Publish Your Web Project

  1. Go to https://fonts.adobe.com.

  2. Sign in with your Adobe ID (same as Creative Cloud).

  3. Find a font and click either the </> icon which is  “Add to Web Project”

    1. If this is the first font you're adding type in a name (e.g., 240 project 2) and to “+Create a new project”

    2. If you already added a project for a previous font then choose that project from the dropdown.

  4. click Create (if new) or Save (if adding)

  5. A dialog box will appear. This has what you need for the link element and your CSS.

  6. Copy the <link> code shown. It will look like this: NOTE do not use this exact code, yours will be specific to your project.
<link rel="stylesheet" href="https://use.typekit.net/hfc8hnn.css">

  1. Paste that line inside the <head> of your HTML file, above your stylesheet link:

<head>
  <meta charset="UTF-8">
  <title>My Project</title>
  <link rel="stylesheet" href="https://use.typekit.net/abcd123.css">
  <link rel="stylesheet" href="style.css">
</head>
  1. Copy the font-family rules and paste them into your CSS file as needed.
--font-heading: "bely-display", sans-serif;
  1. If you're not sure where you will need them right away, then paste them in and comment them out like this:
/* Fonts from Adobe ---------------
font-family: "bely-display", sans-serif;
font-weight: 400;
font-style: normal;

font-family: "bely", serif;
font-weight: 400;
font-style: normal;
------------------ */

@import Method Adobe

This also needs a web project.

✅ Create and Publish Your Web Project

  1. Go to https://fonts.adobe.com.

  2. Sign in with your Adobe ID (same as Creative Cloud).

  3. Find a font and click either the </> icon which is  “Add to Web Project”

    1. If this is the first font you're adding type in a name (e.g., 240 project 2) and to “+Create a new project”

    2. If you already added a project for a previous font then choose that project from the dropdown.

  4. click Create (if new) or Save (if adding)

  5. A dialog box will appear. Click @import in this sentence "If you'd like to use fonts in HTML email, use the @import link."

  6. Copy the @import statement.

    Do NOT copy the <script> tags, jus the @import. It looks like this:

    @import url("https://use.typekit.net/abc134.css");

  1. Paste that line at the very top of your style.css file — it must come before any other CSS rules.

@import url("https://use.typekit.net/abc134.css");
/*other css goes below */

  1. Copy the font-family declaration and then, in your CSS file, paste it in where you need it (Usually in a CSS variable):

--font-heading: "bely-display", sans-serif;
