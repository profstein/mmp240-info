Creating and Accordion

Intro

This guide walks through how use jQuery to make an accordion.

This is different than the jQuery UI Accordion. jQuery UI is an additional set of JavaScript on top of jQuery. I'm not using it here because it adds a lot more JS that you don't need, and it comes with its own styling you would have to override. This way will give you more creative control.
