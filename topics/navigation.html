Navigation

Intro

This page has information on how to add the global navigation to your web site.

Navigation can range from simple to very complex. The focus of this page is responsive navigation that you can use in your projects.

Navigation Walkthroughs

Making a working, accessible nav from scratch can be complicated so most of the time when you're just starting in web design, you will copy someone else's navigation and then adjust it to suit your project. I have some examples with videos in this section and there is an examples section with links to examples you can use. For responsive nav to work JavaScript is often needed. Make sure to identify if the example you are using requires JS and if it does then don't forget to add it to your project.

Implementing Responsive Navigation in Landmarks.

This video shows how to copy and paste the HTML, CSS and JS from this Codepen,Hamburger Menu Responsive , to implement a responsive nav in the NYC Landmarks project.

See the Pen Hamburger Menu Responsive by Christopher Stein (@profstein) on CodePen.

Responsive Navigation with Hamburger Menu

This video explains all of the CSS, HTML and JS that is used to create the navigation. View this if you want to know how it all works. Media queries are added to change the navigation style on larger screens. Because we style the navigation for small screens first and then use media queries for the larger screens, this is an example of mobile-first responsive design.

CodePen Used in the Video

See the Pen Hamburger Menu by Christopher Stein (@profstein) on CodePen.

Responsive Navigation with Text instead of Hamburger Menu

This navigation is mostly the same as the previous responsive navigation but instead of a hamburger menu the word Menu is used. When the nav is open the word changes to Close. This all happens through CSS (the JavaScript is the same) and uses a technique you might not have seen before where text can be added to the screen using ::before or ::after pseudo selectors.

CodePen in the Video

See the Pen Hamburger Menu Responsive by Christopher Stein (@profstein) on CodePen.

Individual Navigation Examples

  1. ModernCSS – CSS-Only Accessible Dropdown Navigation Menu


    Here Stephanie Eckles provides a well-explained CSS-only dropdown nav using modern features like :focus-within.

    Below is a link to the full description of how the navigation menu is created and works. There is also a CodePen fork of it I made that uses CSS variables for the colors to make it easier to adapt to your designs.

    Page describing how the nav is made: https://moderncss.dev/css-only-accessible-dropdown-navigation-menu/

    CodePen with the HTML and CSS that you can copy and use in your project.

    See the Pen CSS-Only Dropdown Navigation Menu by Christopher Stein (@profstein) on CodePen.

  2. CodePen – Simple Responsive Animated Flexbox Navigation (simou)

    Another flexbox nav with a straightforward structure; you can strip out the animation if you want a very minimal base.

    Note that this uses Font Awesome to show the hamburger menu. The first link element in the HTML includes the Font Awesome CSS Library. This library can be very useful if you want to include icons in your project

    https://codepen.io/simou/pen/MWKQeLB

    See the Pen Simple Responsive Animated Flexbox Navigation by mohammed (@simou) on CodePen.

    Mobile-first navigation that’s HTML/CSS only. This one has the hamburger menu button on the left and keeps the nav at the top of the page with fixed position. CSS has helpful comments. I forked the CodePen and made some mods to make it a bit eaiser to copy
