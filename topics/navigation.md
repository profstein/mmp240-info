## Navigation-Only Galleries (Modern “Listamatic-ish” Replacements)

1. **FreeFrontend – CSS Menus (124 CSS Menus)**  
   Large gallery of pure-CSS navigation menus (horizontal, vertical, dropdown, sidebar). Each example links to a live demo and source (often CodePen), easy to mine for simple patterns.  
   https://freefrontend.com/css-menu/  

2. **FreeFrontend – CSS Mobile Menus (19 CSS Mobile Menus)**  
   Collection focused just on mobile/off-canvas menus. Many are checkbox-hack based and CSS-only, good for showing responsive nav variants.  
   https://freefrontend.com/css-mobile-menus/  



4. **Prismic – CSS Menus: 43 Creative Examples for Your Website**  
   Article that curates modern CSS menu examples (with links to live code) – good for pulling a handful of contemporary nav styles rather than one monolithic pattern.  
   https://prismic.io/blog/css-menus  

5. **Slider Revolution – The Best HTML and CSS Menu Examples for Designers**  
   Another curated list of menu examples (horizontal, vertical, dropdown, hamburger). Each example includes a code snippet or a link to full source.  
   https://www.sliderrevolution.com/resources/css-menu/  


## Individual Copy-Pasteable Nav Examples (Good for Students)

6. **ModernCSS – CSS-Only Accessible Dropdown Navigation Menu**  
   Single, well-explained CSS-only dropdown nav using modern features like `:focus-within`. Good “one solid pattern” to show a basic accessible dropdown.  
   https://moderncss.dev/css-only-accessible-dropdown-navigation-menu/  

7. **CodePen – Pure CSS Flexbox Responsive Navbar (nimrodco)**  
   Simple flexbox-based top nav that collapses into a hamburger using a checkbox; plain HTML + CSS, no preprocessor.  
   https://codepen.io/nimrodco/pen/GPwzdQ  

8. **CodePen – Responsive Nav Menu – HTML/CSS Only Mobile (phileflanagan)**  
   Mobile-first navigation that’s HTML/CSS only, with helpful comments in the code. Nice for students to read and adapt.  
   https://codepen.io/phileflanagan/pen/jwbWKP
