Creating a Lightbox Gallery

Intro

This guide walks through how use GLightbox to make a lightbox gallery.

Using GLightbox: Image Lightbox with Captions & Credits

GLightbox is a lightweight (the size of its CSS and JS files is small) JavaScript library that turns a set of image links into a modal (modal is an interactive window or element that appears over other content on the page) lightbox gallery. When a user clicks a thumbnail, a larger version of the image opens in an overlay, with optional captions, credits, next/previous navigation, keyboard support, and looping.

Official resources:

  • Main site & documentation: https://biati-digital.github.io/glightbox/#
  • README on GitHub: https://github.com/biati-digital/glightbox/blob/master/README.md
  • Class example (CodePen): https://codepen.io/profstein/pen/raegExZ

Quick Overview of the Steps

  1. Add the GLightbox CSS file.
  2. Add the GLightbox JavaScript file.
  3. Create gallery HTML using an unordered list with links and images.
  4. Replace the demo images with your own
    • You will have to replace the demo images with your own images and add captions and image credits.
  5. Add the GLightbox Initialize script
  6. Initialize GLightbox with JavaScript.
  7. Add in the Custom Gallery CSS

Step-by-Step Instructions

1. Add the GLightbox CSS

Option A: Download and host locally

  1. Download GLightbox CSS here: glightbox.min.css in GitHub repo. There is a download button on the page or you can click "Raw" and then copy and paste it into a CSS file you make.

  2. Then place the CSS file in your project’s css/ folder (you can also use a vendor folder css/vendor/ like we do for JavaScript).

  3. Then add a link element to it in the head of any .html page you want to use the lightbox.

    <link rel="stylesheet" href="css/glightbox.min.css">

Option B: Use a CDN

For quick demos and class projects, you can load the CSS directly from a CDN.

The CDN is faster. The risk is if the CDN stops supporting the library or the library is updated in a way that breaks your use.

  1. Copy this link: 
    <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/glightbox/dist/css/glightbox.min.css">
  2. Add the link to the head of any .html page you want to use the lightbox.

2. Add the GLightbox JavaScript file

The JavaScript file should be added just before the closing </body> tag of the same page you added the CSS.

Option A: Download and host locally

  1. Download GLightbox JS here: glightbox.min.js in GitHub repo. There is a download button on the page or you can click "Raw" and then copy and paste it into a CSS file you make.

  2. Then place the JS file in your project’s js/vendor folder.

  3. Then add a script element before the closing /body tag of any .html page you want to use the lightbox. You can add it right BEFORE the main.js script if you use my base reponsive page example.

    <script src="js/vendor/glightbox.min.js"></script>

Option B: CDN

If you're using the CDN for the CSS then also use it for the JS.

  1. Copy this link element: 
    <script src="https://cdn.jsdelivr.net/npm/glightbox/dist/js/glightbox.min.js"></script>

  2. Then paste it into the .html page before the closing </body> tag of any .html page you want to use the lightbox. You can add it right BEFORE the main.js script if you use my base reponsive page example.

3. Create the Gallery HTML

Each gallery item is a link (<a>) that points to a large image. Inside the link is a thumbnail image (<img>). The link is what GLightbox turns into the lightbox interaction.

The HTML below only has one image. For more images, copy and paste just the <li> inside of the list. 

<ul class="gallery" role="list">
  <li>
    <figure>
      <a
        href="images/photo-01-large.jpg"
        class="glightbox"
        data-gallery="my-gallery"
        data-type="image"
        data-title="Sunset over the river"
        data-description="Photo by Jane Doe (CC BY 4.0)"
        aria-label="Open larger view: Sunset over the river"
      >
        <img
          src="images/photo-01-thumb.jpg"
          alt="Sun setting over a river with orange light reflecting on the water"
          loading="lazy"
        >
      </a>

      <figcaption>
        Sunset over the river —
        <span class="credit">Photo by Jane Doe (CC BY 4.0)</span>
      </figcaption>
    </figure>
  </li>
</ul>

Important: For images, always include data-type="image". This ensures GLightbox correctly treats the link as an image, even if the image URL does not end with .jpg.

GLightbox can show video as well. this has data type of video.

4. Replace the Demo Images with Your Own

To use your own images, update the following for each gallery item:

It's very important to note that this asks for two versions of each image. the image in the href of that a is the large version people will see when they open the lightbox. the image in the src of the img is the thumbnail they will see before the gallery is opened. You can use your batch processing skills we learned for the landmarks project.

  • in a

    • href → path to the large image
    • data-title → image caption shown in the lightbox
    • data-description and <figcaption> → image credit
    • aria-label keep "Open larger view:" and → change the rest to the same thing you have in data-title

  • in img

    • src → path to the thumbnail image
    • alt → an appropriate alt for your image

  • in figcaption

    change the entire content of the caption to match your image.

The alt attribute should describe what is visible in the image. Credits should appear in the caption, not in alt text.

5. Initialize GLightbox

After the GLightbox script is loaded, it needs to be initialized with a small configuration object. This controls how users interact with the gallery.

Copy and paste the code below into the .html file AFTER the glightbox.min.js file script you already have and BEFORE the closing /body tag.

<script>
  // Initialize GLightbox.
  const lightbox = GLightbox({
    // Only apply the lightbox behavior to links with class="glightbox"
    selector: '.glightbox',

    // Allow users to navigate between images using the keyboard
    keyboardNavigation: true,

    // Show next / previous arrow buttons in the lightbox UI
    arrows: true,

    // Enable circular navigation:
    // - After the last image, "next" goes back to the first
    // - From the first image, "previous" goes to the last
    loop: true
  });
</script>

6. Custom Gallery CSS

To add the finishing touches, you will want to add some of your own custom styles to the gallery.

Below is an example of that. To start you can copy this and paste it into your main .css file. If you prefer to keep things separate, then put them in a new .css file, just remember to also link that to the page.


/*
  The gallery is a semantic unordered list (<ul>).
  We keep the list for meaning, but remove the browser’s default styling.
*/
.gallery {
  list-style: none;   /* Remove default bullet points */
  padding: 0;         /* Remove default left padding added by browsers */
  margin: 0;          /* Remove default top/bottom margin */

  /* Turn the list into a responsive grid */
  display: grid;

  /*
    auto-fit creates as many columns as will fit in the container.
    minmax(220px, 1fr) means:
    - Columns are at least 220px wide
    - They can grow to fill available space
  */
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));

  /* Space between gallery items */
  gap: 1rem;
}

/*
  Images inside the gallery thumbnails
*/
.gallery img {
  width: 100%;        /* Make image fill the width of its container */
  height: auto;       /* Preserve the image’s aspect ratio */
  display: block;     /* Remove inline image spacing below the image */
}

/*
  Browsers add default margins to <figure>.
  We remove them so spacing is fully controlled by our grid and gap.
*/
figure {
  margin: 0;
}

/*
  Photo credit text styling.
  Slightly smaller than body text so it reads as supporting information.
*/
.credit {
  font-size: var(--text-size-sm); /* change to your own variable if needed */
}

/*
  Ensure the document and viewport have a defined height.
  This helps prevent issues with fixed-position overlays (like GLightbox).
*/
html,
body {
  height: 100%;
}

/*
  Allow content to extend naturally.
  This avoids clipping fixed-position overlays in some environments.
*/
body {
  overflow: visible;
}

/*
  Global image safety rule:
  - Images never grow larger than their container
  - Aspect ratio is preserved
*/
img {
  max-width: 100%;
  height: auto;
}
